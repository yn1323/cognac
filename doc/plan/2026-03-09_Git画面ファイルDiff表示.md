# Git画面 ファイルDiff表示 実装計画

## 目的

Git画面の変更ファイル一覧でファイルをクリックすると、右ペインにそのファイルのunified diffを表示する。
未コミットの変更内容を素早く確認するためのUI。レビュー用途や過去コミットのdiff表示は対象外。

## 現状（AsIs）

### PC版レイアウト

```
[サイドバー] | [左カラム: 変更ファイル一覧] | [右カラム: コミット履歴]
```

- 変更ファイル行（`GitFileRow`）はステータスバッジ + パスのみ表示、クリック不可
- diff の内容は一切表示されない（AI解説テキストのみ）

### SP版レイアウト

```
[ヘッダー]
[変更ファイルカード]
[コミット履歴カード]
[ボトムナビ]
```

### 既存のdiff取得機能

| 関数 | 用途 | 実行コマンド |
|:--|:--|:--|
| `getWorkingDiff()` | 全ファイルまとめてdiff | `git diff HEAD` |
| `getStagedDiff()` | ステージ済みdiff | `git diff --staged` |
| `getCommitDiff(hash)` | コミット単体diff | `git show <hash>` |

**ファイル単位のdiff取得は未実装。**

### Step 2: サーバー — ファイル単位diff取得関数

**`server/runner/git-api-ops.ts`** に追加:

```typescript
/**
 * 指定ファイルの未コミットdiff（staged + unstaged）を取得する
 * git diff HEAD -- <path> を実行
 */
export function getFileDiff(cwd: string, filePath: string): string {
  try {
    return git(`diff HEAD -- "${filePath}"`, cwd)
  } catch {
    // HEAD が存在しない場合（初回コミット前）
    return git(`diff --cached -- "${filePath}"`, cwd)
  }
}
```

パスのバリデーション:
- `..` を含むパスは拒否（ディレクトリトラバーサル防止）
- 空文字は拒否

### Step 3: サーバー — APIエンドポイント

**`server/api/git.ts`** に追加:

```typescript
// GET /file-diff?path=xxx — ファイル単位の未コミットdiffを取得
app.get('/file-diff', (c) => {
  const filePath = c.req.query('path')
  if (!filePath) {
    return c.json({ error: 'pathパラメータが必要です' }, 400)
  }
  if (filePath.includes('..')) {
    return c.json({ error: '不正なパスです' }, 400)
  }
  try {
    const diff = getFileDiff(cwd, filePath)
    return c.json({ path: filePath, diff })
  } catch (err) {
    return c.json({ error: 'diffの取得に失敗しました', detail: String(err) }, 500)
  }
})
```

### Step 6: クライアント — GitDiffView コンポーネント（新規）

**`client/components/git-diff-view/`** ディレクトリを新規作成。

#### `git-diff-view.tsx`

unified diff文字列をパースして色付き表示するコンポーネント。

```
[ヘッダー: ファイルパス + ✕ボタン]
[diffコンテンツ: スクロール可能]
  - ハンクヘッダー行（@@...@@）: 灰色背景、`text-muted-foreground`
  - 追加行（+）: `bg-green-50 text-green-800` / dark: `bg-green-950/30 text-green-300`
  - 削除行（-）: `bg-red-50 text-red-800` / dark: `bg-red-950/30 text-red-300`
  - コンテキスト行: 背景なし
  - 行番号: 左側に表示、`text-muted-foreground`、等幅フォント
```

Props:

```typescript
interface GitDiffViewProps {
  path: string
  diff: string | null
  isLoading: boolean
  onClose: () => void
}
```

主な実装方針:
- diff文字列を行単位で `split('\n')` してマップ
- 各行のプレフィックス（`+`, `-`, `@@`, ` `）で色分け
- フォントは `font-mono text-xs`（等幅・小さめ）
- コンテンツエリアは `overflow-auto` で縦横スクロール可能
- 長い行は折り返さない（`whitespace-pre`）
- ロード中は中央にスピナー表示
- diff が空文字の場合は「差分なし」メッセージ
- 外枠は既存の右カラムカードと同じスタイル（`rounded-lg border border-[#e5e5e5] bg-[#fafafa]`）

#### `index.ts`

```typescript

```

## diffパーサーの仕様

unified diff の各行をタイプ分類:

| プレフィックス | タイプ | 表示スタイル |
|:--|:--|:--|
| `@@` | hunk | 灰色背景 `bg-muted text-muted-foreground` |
| `+` | addition | 緑背景 `bg-green-50 dark:bg-green-950/30` |
| `-` | deletion | 赤背景 `bg-red-50 dark:bg-red-950/30` |
| `diff --git` | header | 非表示（ファイル名は別で表示済み） |
| `index`, `---`, `+++` | meta | 非表示 |
| その他 | context | 背景なし |
